French company data as JSON or CSV: the recherche-entreprises (SIRENE) API, its limits, a Python example and a free sample

How to pull French company records from the official open API yourself, which limits and filter traps to expect, what to do about directors and sole traders under the GDPR, and when a normalized feed is worth paying for.

Updated: November 2026. API behaviour below was tested live on 5 November 2026.

The short version

  • France publishes company data as open data (INSEE's SIRENE register, the RNE trade register and more). The official, free, keyless search API is recherche-entreprises.api.gouv.fr: GET /search, JSON out, maintained by the Annuaire des Entreprises team.
  • The rules that matter: 7 requests per second per IP (HTTP 429 above), 25 results per page and a 10,000-result window, and exact NAF codes only (no prefixes, no NAF 2025). Location filters match any establishment, not just the head office.
  • The response includes named directors who are natural persons (name, first names, birth date). That is personal data under the GDPR. The sample on this page has none, and no sole traders either, because a sole trader's business name is a person's name.

1. The recherche-entreprises API

Base URL: https://recherche-entreprises.api.gouv.fr. The interactive documentation is at /docs/ and the OpenAPI file at /openapi.json (it declares API version 1.0.0 and the MIT licence for the API software). No key or login.

curl -s "https://recherche-entreprises.api.gouv.fr/search?q=buffalo+grill&per_page=1"

Limits and errors, as we saw them on 5 November 2026

  • Rate limit: 7 requests per second per IP, and 30 per second per ASN (the docs warn that public clouds will probably hit the ASN limit). Above it the server answers HTTP 429. The docs call these maximums, not guaranteed throughput.
  • per_page is 1 to 25. per_page=26 returns HTTP 400 with the French message "indiquer un paramètre per_page entre 1 et 25". The default is 10.
  • 10,000 results at most per query. page * per_page must not exceed 10,000, and total_results itself is capped: q=boulangerie returned total_results: 10000. Page 401 with per_page=25 is HTTP 400. To go beyond, split the query by department, NAF code, size band or legal form.
  • At least one search parameter is mandatory (HTTP 400, "Veuillez indiquer au moins un paramètre de recherche"). The free-text q needs at least 3 characters.
  • Errors are JSON with a single key erreur, in French.

There is no creation-date filter: date_creation is an output field only, so "companies created last month" cannot be asked of this API.

What the records look like

  • Identifiers: siren (9 digits, the company), siege.siret (14 digits, an establishment). The EU VAT number is derived from the SIREN (tva).
  • Finances come as {"2024": {"ca": ..., "resultat_net": ...}}, keyed by year: use the maximum key for the latest year. In our 20-company sample, 17 have a latest revenue figure.
  • Partial diffusion. When the owner (typically a sole trader) restricts diffusion, the API replaces address and similar fields by the literal string [NON-DIFFUSIBLE]. In four pages of sole traders in the Rhône we counted 192 such strings. Fully non-diffusible companies are not served at all, and neither are companies whose trade-register registration was refused.
  • Commercial prospecting flag: opposition_diffusion_commerciale is true when the business objected to being used for commercial prospecting. 14 of the 20 companies in our sample have it set, so large companies use it too.
  • Directors: dirigeants mixes legal entities (personne morale: SIREN and denomination) and natural persons (personne physique), whose entries carry nom, prenoms, date_de_naissance and nationalite.
  • Freshness: date_mise_a_jour was within the day for the companies we checked; INSEE and trade-register fields have their own update dates (date_mise_a_jour_insee, date_mise_a_jour_rne).
  • This is a search API, not the full SIRENE base. The docs say it cannot give the complete SIRENE data; for the full stock files use the data.gouv.fr dataset (section 5).

2. DIY: companies to CSV in Python

This script (tested on 5 November 2026: 10,000 matches for two software NAF codes in Paris, 100 written) pages through results under the rate limit, retries on 429 and 5xx, leaves sole traders out and flattens the head-office address and the latest revenue. It needs pip install requests. Directors are deliberately not read.

import csv
import time

import requests

URL = "https://recherche-entreprises.api.gouv.fr/search"
# activite_principale takes EXACT NAF rev. 2 codes (e.g. 62.01Z). "62" or "62.0" is HTTP 400
# and the error lists the 732 valid codes. NAF 2025 codes are not accepted.
NAF = ["62.01Z", "62.02A"]
PARAMS = {
    "activite_principale": ",".join(NAF),
    "departement": "75",                       # matches companies with ANY establishment in Paris, not only head offices
    "etat_administratif": "A",                 # active only
    "est_entrepreneur_individuel": "false",    # leave sole traders out: their business name is a person's name
    "per_page": 25,                            # 1-25, above is HTTP 400
}
MAX_WINDOW = 10_000                            # page * per_page must not exceed this, whatever total_results says

rows, page = [], 1
while page * PARAMS["per_page"] <= MAX_WINDOW and len(rows) < 100:     # demo: 100 companies
    for attempt in range(5):
        r = requests.get(URL, params={**PARAMS, "page": page}, timeout=30)
        if r.status_code in (429, 500, 502, 503, 504):
            time.sleep(int(r.headers.get("Retry-After", 2 ** attempt)))
            continue
        r.raise_for_status()                   # 400 = JSON {"erreur": "..."}
        break
    data = r.json()
    if page == 1:
        print(data["total_results"], "matches (capped at 10000)")
    for c in data["results"]:
        s = c.get("siege") or {}
        fin = (c.get("finances") or {})
        last = max(fin) if fin else None       # {"2024": {"ca": ..., "resultat_net": ...}}
        rows.append({
            "siren": c["siren"], "name": c["nom_complet"], "naf": s.get("activite_principale"),
            "legal_form": c.get("nature_juridique"), "employees_band": c.get("tranche_effectif_salarie"),
            "category": c.get("categorie_entreprise"), "created": c.get("date_creation"),
            "hq_city": s.get("libelle_commune"), "hq_postcode": s.get("code_postal"),
            "revenue": fin[last].get("ca") if last else None, "revenue_year": last,
            "url": f"https://annuaire-entreprises.data.gouv.fr/entreprise/{c['siren']}",
        })
    if page >= data["total_pages"]:
        break
    page += 1
    time.sleep(0.2)                            # stay far below 7 requests per second per IP

with open("companies_fr.csv", "w", newline="", encoding="utf-8") as f:
    w = csv.DictWriter(f, fieldnames=rows[0].keys())
    w.writeheader()
    w.writerows(rows)
print(len(rows), "companies written")

3. When the Actor saves time

For a one-off list, the script is enough and free. The Apify Actor France Company Search (by Nexus Scrapers) wraps the same official API. It pays off when you would otherwise maintain that code:

  • NAF prefixes and NAF 2025. You pass 62 or 62.0 and the Actor expands it into the exact rev. 2 codes; NAF 2025 codes are mapped back to rev. 2 through INSEE's correspondence table. Both NAF versions are in the output, with official labels for NAF, legal form, size band, region and department.
  • A flat, stable record: head office as one object, latest and historical revenue, labels as a list, SIREN-based VAT number, source link, null for hidden values ([NON-DIFFUSIBLE] is converted to null and the record says diffusionStatus: partial).
  • Privacy defaults: natural-person directors are dropped in memory and never reach the dataset; legal-entity directors are kept. An includeDirectors option exists, adds personal data and makes you responsible for it; it is never applied to partial-diffusion companies. There are inputs to exclude sole traders and companies that objected to commercial prospecting.
  • Lookups by SIREN or SIRET in bulk, input validation, retries and pacing (4 requests per second, below the limit).
  • Scheduling and integrations through Apify: runs into Slack, e-mail, Google Sheets or a webhook; export as JSON, CSV or Excel; API and MCP access.

Pricing is pay per result; the Actor page shows the current price.

Limits: it inherits the API's 10,000-result window (split by department or NAF to go beyond), the establishment-level location filter, the lack of a creation-date filter and the absence of non-diffusible companies. It has no beneficial-owner data and no filed accounts documents. For a single list, use the script.

4. Real sample: 20 normalized records

These 20 records were produced on 5 November 2026 by running the Actor's own code locally on live API responses (no Apify platform involved): 12 software-programming companies (NAF 62.01Z) with an establishment in Paris and 50 to 249 employees, 4 restaurant companies (56.10A) with an establishment in the Rhône and 4 supermarket companies (47.11D) with an establishment in Occitanie, largest first. Because of the establishment-level location filter, several head offices are elsewhere, and the workforce band is that of the company, so a few show no employees at all. They are the first matches in that order, not hand-picked for quality.

No natural-person data. Sole traders were excluded with the Actor's own filter, natural-person directors are dropped by default (the only directors kept are legal entities), and there are no contacts. A scrub pass over all text fields found no e-mail address or phone number. The names are company names; the head-office address is the registered business address.

5. Data licence and terms

The underlying register data is open data. The SIRENE dataset on data.gouv.fr (publisher: INSEE) is under the Licence Ouverte / Open Licence 2.0 (Etalab): free reuse, commercial included, if you credit the source and the date of the last update. The API's own page on api.gouv.fr says "Licence non renseignée", and its OpenAPI file declares MIT for the software, so the data licence is the one of the sources, not of the API. Credit "INSEE, base Sirene" and the Annuaire des Entreprises, and say when you downloaded the data.

Two obligations sit outside the licence. Diffusion restrictions: the API already hides what owners asked to hide, and you must not try to recover it from other fields. Personal data: a sole trader's name and the names and birth dates of directors are personal data under the GDPR even though they are public; reuse needs your own lawful basis and information duties. Businesses may also object to commercial prospecting (opposition_diffusion_commerciale); respect it when you build marketing lists. This is a summary, not legal advice.
